# 📝 Django Todo App

A simple and user-friendly **Todo List web application** built using **Python and Django**. This project was created to understand the fundamentals of Django and learn how the frontend and backend work together.

## ✨ Features

* ➕ Add new tasks
* 📋 View all tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 📊 Display the total number of tasks
* 🎨 Custom HTML and CSS styling
* 💾 Store tasks using Django's database system

## 🛠️ Technologies Used

* **Python** – Backend programming
* **Django** – Web framework
* **HTML5** – Page structure
* **CSS3** – Styling and design
* **SQLite** – Database
